# Оргтехник — сайт мастерской в Обнинске

Одностраничный сайт на чистом HTML, CSS и JS. Без сборки, без зависимостей,
без базы данных — папку можно просто положить на любой хостинг.

## Посмотреть локально

```
powershell -ExecutionPolicy Bypass -File serve.ps1
```

Затем открыть <http://localhost:8080/>. Окно PowerShell должно оставаться открытым,
пока смотрите сайт; остановить — `Ctrl+C` в нём же.

Можно и просто открыть `index.html` двойным щелчком, но тогда не загрузится карта
и часть шрифтов — браузер ограничивает локальные файлы.

## Что где лежит

| Файл | Что в нём |
|---|---|
| `index.html` | вся страница: тексты, разделы, микроразметка для поиска |
| `policy.html` | политика обработки персональных данных (нужна из-за формы заявки) |
| `consent.html` | согласие на обработку персональных данных — отдельный документ, на него ведёт галочка в форме |
| `css/styles.css` | оформление; палитра — в самом верху, в блоке `:root` |
| `css/fonts.css`, `fonts/` | шрифты Onest и Unbounded — лежат у нас, а не у Google |
| `js/app.js` | шапка, меню, проверка формы |
| `js/cartridges.js` | справочник 93 моделей картриджей; **к сайту не подключён** |
| `img/hero-*.jpg` | фотография в шапке в трёх размерах |
| `img/detail-*.jpg` | крупные планы, нарезанные из той же фотографии |
| `serve.ps1` | локальный просмотр |
| `Открыть сайт.bat` | двойной щелчок — запускает сервер и открывает браузер |
| `ЦЕНЫ-ПРОВЕРИТЬ.md` | список всего, что нужно подтвердить перед запуском |

## Как поменять цены

Все цены лежат в одном месте — в `index.html`, в разделе `<section id="price">`,
обычным текстом внутри `<p class="svc__price">`. Никакого кода трогать не нужно.

Подробности и список того, что стоит уточнить у Станислава, —
в [ЦЕНЫ-ПРОВЕРИТЬ.md](ЦЕНЫ-ПРОВЕРИТЬ.md).

## Как добавить или убрать услугу

Скопировать соседний блок в `index.html`:

```html
<article class="svc">
  <h3 class="svc__name">Название услуги</h3>
  <p class="svc__price">от&nbsp;900&nbsp;₽</p>
  <p class="svc__desc">Одно-два предложения: что именно делаем и что получит клиент.</p>
</article>
```

Порядок блоков в файле — это порядок на странице.

## Почему на сайте нет таблицы моделей

Была, но убрали. Человек с пустым картриджем обычно не знает, что на нём написано,
и искать модель самому — лишний барьер. Вместо этого в блоке цен стоит короткий путь:
сфотографировать картридж и прислать в WhatsApp либо позвонить и назвать принтер.
Кнопка WhatsApp открывается с уже написанным текстом сообщения.

## Форма заявки

Открывает WhatsApp с уже набранным текстом заявки. Сервер для этого не нужен,
работает на любом статическом хостинге. Если понадобится отправка на почту —
меняется обработчик `submit` в конце `js/app.js`.

## Публикация

Залить содержимое папки в корень хостинга. Файлы `serve.ps1`, `README.md`
и `ЦЕНЫ-ПРОВЕРИТЬ.md` заливать не нужно — они для работы, не для сайта.

Перед запуском на боевом домене стоит:

1. проверить цены по [ЦЕНЫ-ПРОВЕРИТЬ.md](ЦЕНЫ-ПРОВЕРИТЬ.md);
2. подключить Яндекс.Метрику, если нужна статистика;
3. настроить переадресацию со старых адресов (`/price.html`, `/contact.html`,
   `/faq.html`, `/reviews.html`, `/online-zaiavka.html`) — они годами в индексе,
   и их лучше не терять:
   - `/price.html` → `/#price`
   - `/contact.html` → `/#contacts`
   - `/online-zaiavka.html`, `/callback.html` → `/#order`
   - остальные → `/`

## Особенности вёрстки

- Палитра снята пипеткой с фотографии в шапке: фон страницы — цвет стены в кадре,
  акцент — бирюза фотовала на столе. Страница визуально продолжает фотографию.
- Все крупные планы (`img/detail-*.jpg`) вырезаны из этой же съёмки, стока нет.
- Шрифты **Unbounded** (заголовки) и **Onest** (текст) лежат в `fonts/` и подключаются
  через `css/fonts.css`, а не с серверов Google: так браузер посетителя не отдаёт свой
  IP-адрес за границу. Лицензия SIL OFL это разрешает. Только артефакт-превью берёт их
  с Google — своих файлов он не видит.
- **Юридическое.** Галочка в форме ведёт на отдельную страницу согласия — так требует
  закон с 1 сентября 2025 года. Карта Яндекса ставит cookie, поэтому загружается только
  по кнопке «Показать карту», выбор запоминается в браузере. Английские надписи на снимках
  закрашены из-за закона о русском языке (с 1 марта 2026). Мастер-файлы без надписей:
  `C:\Claude\Photo\IMG_7902-ru.png` и `workshop-ru.jpg` — картинки в `img/` собирать из них.
- Строки услуг, плашки сроков и блоки для офисов подсвечиваются под курсором.
  На тач-экранах подсветка отключается — там нет курсора.
- **Кадры обложки.** `hero-1536.jpg` и `hero-1024.jpg` — снимок целиком.
  `hero-mobile.jpg` — отдельный кроп для телефона **5:4**: область `720, 120`
  размером `780 × 624` из `IMG_7902-ru.png`, выведенная в 1040 × 832. В нём
  видно и лицо мастера, и раскрытый принтер с отвёрткой, но по высоте он вдвое
  ниже вертикального — только так на первый экран влезают ещё и заголовок, текст
  и кнопки. Высота блока считается **от ширины экрана** (`aspect-ratio: 5/4`),
  а не от высоты окна: во встроенных окнах вроде страницы артефакта высота окна
  меньше экрана, и кадр начинал обрезаться снизу.
- **Фотография отретуширована.** Исходник — `C:\Claude\Photo\IMG_7902.png`,
  версия без надписей — `IMG_7902-clean.png`; а файлы в `img/` теперь собираются
  из `IMG_7902-ru.png` — в нём ещё и закрашена английская табличка на полке. Фразы «Продлеваем жизнь вашей технике» и «Надежная печать каждый
  день» сняты со снимка и набраны текстом (`.hero-cap` в `index.html`):
  Onest Light, кегль и трекинг подобраны так, что строки совпадают с прежними
  до пикселя. Так они остаются резкими, когда фотография растягивается
  на широкий экран. Позиционирует их тот же код, что и области на плашках.
- **Плашки «Ремонт / Заправка / Обслуживание» нарисованы внутри фотографии.**
  Поверх них лежат прозрачные ссылки (`.hotspot` в `index.html`): при наведении
  подсвечиваются, показывают цену и ведут в нужный раздел. Кадр обрезается
  по-разному на разных экранах, поэтому положение считает `js/app.js` — объект
  `SPOTS` хранит границы в долях исходного снимка. **Если менять `object-position`
  у обложки или саму фотографию, координаты в `SPOTS` надо пересчитать.**
  На телефоне подставляется вертикальный кроп без этих надписей, и области скрыты.
- Тёмная тема жёстко задана: сайт выглядит одинаково при любых настройках системы.
- Из анимаций — только появление первого экрана; при «уменьшить движение» отключается.
- Карта — виджет Яндекса, метка по координатам `55.087326, 36.601510`. Грузится
  только по кнопке «Показать карту» (адрес виджета — `MAP_SRC` в `js/app.js`);
  до этого на её месте адрес и ссылка «Открыть в Яндекс Картах».
